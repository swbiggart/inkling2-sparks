# Security

Please report a vulnerability privately, through this repository's
[private vulnerability reporting form](https://github.com/swbiggart/inkling2-sparks/security/advisories/new)
(Security tab, "Report a vulnerability"), not in a public issue.

Include the version (`v0.1`), what you found, and how to reproduce it. Reports are handled on a best-effort basis; a
fix ships as a new version, and the v0.1 release asset is never replaced.

A problem in upstream TensorFold's own code belongs to [TensorFold](https://github.com/ashhart/TensorFold); a problem
in the model belongs to Thinking Machines.

Deployment notes (loopback default, API keys, the fabric): the README's
[Security](README.md#security) section.
